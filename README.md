# Subscriber-Side Multi-Variant Fast Switching for Media over QUIC

This is the working area for an individual Internet-Draft, "Subscriber-Side
Multi-Variant Fast Switching for Media over QUIC". It is not yet adopted by
the IETF MOQ Working Group.

* [Editor's Copy](https://moqtail.github.io/draft-ugur-moq-fast-switching/#go.draft-ugur-moq-fast-switching.html)
* [Datatracker Page](https://datatracker.ietf.org/doc/draft-ugur-moq-fast-switching)
* [Individual Draft](https://datatracker.ietf.org/doc/html/draft-ugur-moq-fast-switching)
* [Compare Editor's Copy to Individual Draft](https://moqtail.github.io/draft-ugur-moq-fast-switching/#go.draft-ugur-moq-fast-switching.diff)

## Command Line Usage

Formatted text and HTML versions of the draft can be built using `make`.

```sh
$ make
```

Command line usage requires that you have the necessary software installed.
See [the instructions](https://github.com/martinthomson/i-d-template/blob/main/doc/SETUP.md).
